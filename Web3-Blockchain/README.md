# Web3 & Blockchain Development - Comprehensive Guide

## Overview

Welcome to the **Web3 & Blockchain** section of RunexisForge! This section covers the decentralized web, blockchain technology, smart contract development, and decentralized application (DApp) creation. From foundational concepts of Bitcoin and Ethereum to modern development with Solidity, Rust, and various frameworks.

---

## 🏗️ Core Ethereum Development

### **Ethereum**
The leading smart contract platform.
- **Concepts**: Blockchain, EVM, Gas, Accounts, Transactions
- **Docs**: [Ethereum Guide](./Ethereum/ethereum.md)

### **Solidity**
The primary language for Ethereum smart contracts.
- **Features**: Object-oriented, statically typed
- **Docs**: [Solidity Guide](./Solidity/solidity.md)

### **Web3.js & Ethers.js**
Libraries to interact with Ethereum nodes.
- **Use**: Frontend DApp integration
- **Docs**: [Web3.js Guide](./Web3JS/web3js.md)

## 🛠️ Development Frameworks

### **Hardhat**
A flexible Ethereum development environment.
- **Lang**: JavaScript/TypeScript
- **Docs**: [Hardhat Guide](./Hardhat/hardhat.md)

### **Foundry**
A blazing fast, portable and modular toolkit for Ethereum application development written in Rust.
- **Lang**: Solidity (Scripting), Rust (Core)
- **Docs**: [Foundry Guide](./Foundry/foundry.md)

### **Truffle**
A world-class development environment, testing framework and asset pipeline.
- **Lang**: JavaScript
- **Docs**: [Truffle Guide](./Truffle/truffle.md)

## 🚀 Getting Started Roadmap

1.  **Understand Blockchain Basics**: Start with Bitcoin and Ethereum concepts.
2.  **Learn Solidity**: Master the language of smart contracts.
3.  **Choose a Framework**: Hardhat is recommended for beginners/TS users, Foundry for advanced/speed.
4.  **Connect Frontend**: Learn Web3.js or Ethers.js to connect React/Vue apps to blockchain.
5.  **Build Projects**: Create your own tokens (ERC-20, NFT), DAOs, or DeFi apps.
