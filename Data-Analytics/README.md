# Data Analytics & Machine Learning

A comprehensive collection of data analytics, machine learning, and AI tools organized by functionality.

## 📂 Categories

### 01-Data-Processing
Core libraries and tools for data manipulation, transformation, and analysis.

- **Pandas** - Powerful data manipulation and analysis library
- **NumPy** - Fundamental package for numerical computing
- **DuckDB** - In-process analytical SQL database
- **dbt** - Data transformation workflow tool

### 02-Distributed-Computing
Frameworks for large-scale distributed data processing and parallel computing.

- **Apache Spark** - Unified analytics engine for big data processing
- **Dask** - Flexible parallel computing library for analytics
- **Ray** - Distributed framework for scaling Python applications

### 03-Machine-Learning
Traditional machine learning libraries and gradient boosting frameworks.

- **Scikit-learn** - Classic machine learning algorithms and tools
- **LightGBM** - Fast gradient boosting framework
- **XGBoost** - Scalable gradient boosting system
- **RAPIDS** - GPU-accelerated data science and machine learning

### 04-Deep-Learning
Neural network and deep learning frameworks.

- **TensorFlow** - End-to-end machine learning platform
- **PyTorch** - Dynamic deep learning framework
- **OpenCV** - Computer vision library for image and video processing
- **YOLO** - Real-time object detection and computer vision

### 05-ML-Operations
Tools for managing ML lifecycle, experiment tracking, and model deployment.

- **MLflow** - Open-source platform for ML lifecycle management
- **Kubeflow** - ML toolkit for Kubernetes
- **Weights-and-Biases** - Experiment tracking and model management

### 06-AI-LLM
Large Language Models, AI APIs, and LLM application frameworks.

- **OpenAI-GPT** - OpenAI's GPT models and API
- **Anthropic-Claude** - Anthropic's Claude AI assistant
- **HuggingFace** - Transformers and pre-trained models hub
- **LangChain** - Framework for developing LLM-powered applications
- **NLTK** - Natural Language Toolkit for NLP tasks
- **spaCy** - Industrial-strength natural language processing
- **Stable Diffusion** - Text-to-image generation and AI art

### 07-Streaming-Platforms
Real-time data streaming and event-driven architectures.

- **Apache Kafka** - Distributed event streaming platform
- **Apache Pulsar** - Cloud-native distributed messaging and streaming

### 08-Workflow-Orchestration
Tools for scheduling, monitoring, and managing data pipelines.

- **Airflow** - Platform to programmatically author, schedule, and monitor workflows

### 09-Data-Platforms
Cloud data warehouses and modern data lakehouse architectures.

- **Snowflake** - Cloud data platform and warehouse
- **Lakehouse** - Modern data architecture combining lakes and warehouses

### 10-Visualization-Apps
Interactive data visualization and application building frameworks.

- **Streamlit** - Framework for building data apps quickly
- **Cuba** - Lightweight web framework for data-driven applications

## 🎯 Common Workflows

### Data Science Pipeline
1. **Processing** - Pandas/NumPy for data cleaning
2. **ML** - Scikit-learn for modeling
3. **Tracking** - MLflow for experiment management
4. **Visualization** - Streamlit for dashboards

### Deep Learning Project
1. **Framework** - TensorFlow/PyTorch for model development
2. **Orchestration** - Kubeflow for training at scale
3. **Tracking** - Weights-and-Biases for experiments
4. **Deployment** - MLflow for model serving

### Big Data Analytics
1. **Processing** - Apache Spark for distributed computing
2. **Streaming** - Apache Kafka for real-time data
3. **Orchestration** - Airflow for workflow management
4. **Storage** - Snowflake/Lakehouse for data warehousing

### LLM Application
1. **Framework** - LangChain for app development
2. **Models** - HuggingFace/OpenAI-GPT/Anthropic-Claude
3. **Interface** - Streamlit for user interaction

## 📖 Usage Guidelines

Each tool has its own dedicated folder containing:
- Comprehensive documentation (`.md` files)
- Example code (`examples/` directory)
- Practice questions (`questions/` directory)

Navigate to specific category and tool folders for detailed information.

## 🛠️ Technology Stack Recommendations

### For Beginners
- Start with: Pandas, NumPy, Scikit-learn, Streamlit
- Progress to: TensorFlow/PyTorch, MLflow

### For Production Systems
- Data: dbt, Apache Spark, Snowflake
- ML: TensorFlow/PyTorch, Kubeflow, MLflow
- Orchestration: Airflow
- Streaming: Apache Kafka

### For AI/LLM Development
- Frameworks: LangChain
- Models: OpenAI-GPT, Anthropic-Claude, HuggingFace
- Apps: Streamlit
