# GarudaLinux

## Introduction

Garuda Linux is an Arch-based distribution focused on performance, ease-of-use, and attractive defaults (Btrfs, gaming tweaks, GUI tools).

- Base: Arch Linux
- Package manager: pacman (AUR supported)
- Traits: Btrfs with snapshots, curated desktops, Garuda Assistant

---

## User Guide

## Update & Upgrade

```bash
sudo pacman -Syu
```bash

## Install Software

```bash
sudo pacman -S <pkg>
```bash

## Snapshots (Btrfs)

- Manage snapshots via GUI tools; rollback via boot menu.

## Install Garuda Linux

- Download ISO: <https://garudalinux.org/downloads.html>
- Create bootable USB, boot installer
- Includes Btrfs with snapshots and GUI tools
- More: [../INSTALL.md](../INSTALL.md)

## AUR

- Use an AUR helper (e.g., `yay`) for community packages.
