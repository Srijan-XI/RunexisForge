# Tails

## Introduction

## What is Tails?

**Tails** (The Amnesic Incognito Live System) is a security-focused Debian-based Linux distribution aimed at preserving privacy and anonymity. It connects to the Internet exclusively through the Tor network and leaves no trace on the computer being used.

---

## Why Choose Tails?

- **🔒 Privacy First**: All connections through Tor
- **🕵️ Anonymous**: Leave no trace
- **💿 Live System**: Runs from USB/DVD
- **🛡️ Secure**: Built-in encryption
- **🆓 Free**: Open-source and free
- **🌐 Censorship Resistant**: Bypass restrictions

---

## Key Features

### Privacy & Anonymity

- **Tor Network**: All traffic anonymized
- **No Traces**: Amnesia feature clears memory
- **Encrypted Storage**: Persistent volume encryption

### Security Tools

- **Tor Browser**: Anonymous web browsing
- **Encrypted Messaging**: Pidgin with OTR
- **Email Encryption**: Thunderbird with OpenPGP
- **KeePassXC**: Password manager

---

## Use Cases

- Journalists protecting sources
- Activists in restrictive countries
- Privacy-conscious users
- Whistleblowers
- Secure communication

---

## System Requirements

- **RAM**: 2 GB minimum
- **Storage**: 8 GB USB stick
- **CPU**: Any recent processor
- **Boot**: USB boot capability

---

## ⚠️ Important Notes

- Not meant for daily desktop use
- Requires USB stick/DVD
- Internet slower (Tor routing)
- Some websites may block Tor

## User Guide

## Installation

### Create Tails USB

1. Download from [tails.boum.org](https://tails.boum.org/install/)
2. Verify download (important for security)
3. Use Tails Installer or Etcher
4. Create bootable USB
5. Restart and boot from USB

---

## First Boot

### Boot Menu

1. Access BIOS/UEFI
2. Select USB as boot device
3. Tails boot menu appears
4. Select "Tails"

---

## Using Tails

### Tor Browser

- Pre-configured for anonymity
- Never use personal accounts
- HTTPS Everywhere enabled

### Persistent Storage (Optional)

```
Applications → Tails → Configure persistent volume
1. Create passphrase
2. Select what to save:
   - Personal files
   - Browser bookmarks
   - Email client
   - Network connections
3. Restart to activate
```

---

## Security Tips

- ⚠️ Never use personal information
- ⚠️ Don't torrent (reveals IP)
- ⚠️ Use HTTPS sites
- ⚠️ Don't maximize Tor Browser
- ⚠️ Update regularly
