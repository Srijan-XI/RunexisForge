# MX_Linux

## Introduction

## What is MX Linux?

**MX Linux** is a cooperative venture between the antiX and former MEPIS Linux communities. It's a midweight distribution that combines elegant and efficient desktop with simple configuration, high stability, solid performance, and medium-sized footprint.

---

## Why Choose MX Linux?

- **🏆 #1 on DistroWatch**: Most popular Linux distro
- **⚡ Lightweight**: Runs well on older hardware
- **🔧 MX Tools**: Unique system management tools
- **📦 Debian Stable**: Rock-solid base
- **🎨 Xfce Desktop**: Fast and customizable
- **👥 Community**: Friendly and helpful

---

## Key Features

### MX Tools

- **MX Package Installer**: Easy software installation
- **MX Snapshot**: System backup and restore
- **MX Boot Repair**: Fix boot issues
- **MX Tweak**: System customization
- **MX Live USB Maker**: Create live USBs

### Performance

- **antiX Magic**: Efficient system design
- **SysVinit & systemd**: Choice of init system
- **AppImages**: Portable applications

## Installation

1. Download from [mxlinux.org](https://mxlinux.org/download-links/)
2. Create bootable USB
3. Boot from USB
4. Run installer
5. Follow wizard

---

## MX Tools

### Access MX Tools

```bash
Menu → System → MX Tools
```bash

### Common Tools

```bash
- MX Package Installer (software)

- MX Boot Repair (fix GRUB)

```bash

---

## Package Management

```bash
# Update
sudo apt update && sudo apt upgrade

# Install
sudo apt install <package>

# Or use MX Package Installer (GUI)
```bash

---

## Create System Snapshot

```bash
MX Tools → MX Snapshot
1. Choose type (full/home)
2. Enter description
3. Click "Create Snapshot"
4. Wait for completion
```bash
