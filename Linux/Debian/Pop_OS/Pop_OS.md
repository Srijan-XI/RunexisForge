# Pop_OS

## Introduction

## What is Pop!_OS?

**Pop!_OS** is a free, open-source Linux distribution developed by System76, designed for developers, makers, and computer science professionals. Based on Ubuntu, it offers a streamlined experience with a focus on productivity and creativity.

---

## Why Choose Pop!_OS?

- **🚀 Developer-Focused**: Optimized for coding and development
- **🎮 Gaming Ready**: NVIDIA/AMD GPU support out-of-box
- **⌨️ Keyboard-Driven**: Powerful tiling window manager
- **🔧 System76 Hardware**: Optimized for System76 computers
- **📊 Performance**: Minimal bloat, maximum speed
- **🆓 Free & Open**: Completely free to use

---

## Key Features

### Pop Shell

- **Auto-tiling**: Automatic window tiling
- **Keyboard shortcuts**: Efficient workflow
- **Workspace management**: Easy multi-desktop switching

### Built-in Tools

- **Pop!_Shop**: Curated application store
- **NVIDIA ISO**: Dedicated ISO with NVIDIA drivers
- **Power Profiles**: Easy battery/performance management
- **Firmware Manager**: Easy hardware updates

---

## Editions

### Pop!_OS (Intel/AMD)

- For Intel or AMD graphics
- Standard kernel

### Pop!_OS (NVIDIA)

- Pre-installed NVIDIA drivers
- Optimized for NVIDIA GPUs

---

## System Requirements

- **CPU**: 64-bit x86 processor
- **RAM**: 4 GB minimum (8 GB+ recommended)
- **Storage**: 20 GB minimum
- **GPU**: Intel, AMD, or NVIDIA

## User Guide

## Installation

1. Download ISO from [pop.system76.com](https://pop.system76.com/)
2. Choose Intel/AMD or NVIDIA version
3. Create bootable USB
4. Boot and install
5. Restart

---

## Pop Shell (Tiling)

### Enable Auto-Tiling

```bash
Super + Y (toggle tiling)
```bash

### Keyboard Shortcuts

```bash
Super + Enter - Terminal
Super + / - Launcher
Super + O - Workspaces
Super + Arrow Keys - Move focus
Super + Shift + Arrow Keys - Move windows
```bash

---

## Package Management

```bash
# Update
sudo apt update && sudo apt upgrade

# Install
sudo apt install <package>

# Flatpak (pre-installed)
flatpak install <app>
```bash

---

## Gaming

### Install Steam

```bash
# Via Pop!_Shop or
sudo apt install steam
```bash

### GameMode (pre-installed)

```bash
# Runs automatically with games
gamemoderun <game>
```bash
