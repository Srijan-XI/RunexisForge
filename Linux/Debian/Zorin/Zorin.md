# Zorin

## Introduction

## What is Zorin OS?

**Zorin OS** is a Ubuntu-based Linux distribution designed specifically to make the transition from Windows and macOS to Linux as smooth as possible. It features a familiar desktop environment and comes with pre-installed software for everyday computing tasks.

---

## Why Choose Zorin OS?

- **🪟 Windows-Like Interface**: Familiar desktop layout for Windows users
- **🎨 Beautiful Design**: Modern, polished user interface
- **📱 Touch Support**: Optimized for touchscreens
- **🆓 Free Version**: Zorin OS Core is completely free
- **🔄 Easy Transition**: Designed for Windows/Mac switchers
- **⚡ Performance**: Lightweight options available

---

## Editions

### Zorin OS Core (Free)

- Modern desktop experience
- Pre-installed essential apps
- Based on Ubuntu LTS

### Zorin OS Lite (Free)

- For older/slower hardware
- XFCE desktop environment
- Minimal resource usage

### Zorin OS Pro ($39)

- Premium desktop layouts
- Advanced productivity apps
- Professional creative software
- Priority support

### Zorin OS Education

- For schools and students
- Educational software included
- Parental controls

---

## Key Features

- **Zorin Appearance**: Desktop layout customization
- **Windows App Support**: Wine and PlayOnLinux pre-installed
- **Software Center**: Easy app installation
- **Touch Gestures**: Multi-touch support
- **Built-in Apps**: LibreOffice, GIMP, Firefox, Thunderbird

---

## System Requirements

### Minimum

- **CPU**: 1 GHz Dual Core
- **RAM**: 2 GB (Core), 1 GB (Lite)
- **Storage**: 10 GB

### Recommended

- **CPU**: 2 GHz Dual Core or better
- **RAM**: 4 GB+
- **Storage**: 20 GB+ SSD

## User Guide

## Installation

1. Download ISO from [zorin.com](https://zorin.com/os/download/)
2. Create bootable USB with Rufus/Etcher
3. Boot from USB
4. Follow installation wizard
5. Restart and enjoy

---

## Desktop Layouts

### Change Layout

```
Zorin Appearance → Layouts
- Windows-like
- macOS-like
- GNOME-like
- Touch-optimized
```

---

## Package Management

```
# Update system
sudo apt update && sudo apt upgrade

# Install software
sudo apt install <package-name>

# Or use Software Center (GUI)
```

---

## Windows Software

### Using Wine

```
# Install Windows app
wine setup.exe

# Or use PlayOnLinux (pre-installed)
```
