# ParrotSec

## Introduction

Parrot OS is a Debian-based distribution focused on security, privacy, and development, offering editions for pentesting and home use.

- Base: Debian
- Package manager: APT
- Traits: Security tools, privacy defaults, multiple editions

---

## User Guide

## Update & Upgrade

```bash
sudo apt update
sudo apt upgrade
```bash

## Install Tools

```bash
sudo apt install parrot-tools
```bash

## Install Parrot OS

- Download ISO: <https://www.parrotsec.org/download/>
- Create bootable USB, boot installer
- Choose Home, Pentesting, or Security editions
- More: [../INSTALL.md](../INSTALL.md)

## Privacy

- Includes privacy tools; review settings and browser profiles.
