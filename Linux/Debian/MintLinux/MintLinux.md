# MintLinux

## Introduction

Linux Mint is an Ubuntu-based desktop distribution focused on ease-of-use, stability, and a familiar interface (Cinnamon, MATE, Xfce).

- Base: Ubuntu (Debian)
- Package manager: APT
- Traits: Beginner-friendly, Update Manager, multimedia codecs

---

## User Guide

## Update & Upgrade

- Use Update Manager GUI or terminal:

```bash
sudo apt update
sudo apt upgrade
```bash

## Install Software

- Software Manager GUI or:

```bash
sudo apt install <pkg>
```bash

## Install Linux Mint

- Download ISO: <https://linuxmint.com/download.php>
- Create bootable USB, boot, run installer
- Beginner-friendly; choose desktop (Cinnamon/MATE/Xfce)
- More: [../INSTALL.md](../INSTALL.md)

## Snap/Flatpak

- Mint favors Flatpak; enable and install via GUI or `flatpak`.
