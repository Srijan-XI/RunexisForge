## 🚀 Getting Started by Use Case

### I want to build a... 

#### **REST API**

2. Alternative: [Sails.js](./Sails.js/Sails.js.md)

1. Start here: [Sails.js](./Sails.js/Sails.js.md) (WebSocket built-in)
2. Alternative: [Express](./Express/Express.md) + Socket.io

#### **Enterprise Application**
1. Start here: [NestJS](./NestJS/NestJS.md)
2. Alternative: [Hapi](./Hapi/Hapi.md)
3. For Rust: [Actix-web](./Actix-web/Actix-web.md)

#### **High-Performance Service**
1. [Fastify](./Fastify/Fastify.md) (JavaScript)
2. [Actix-web](./Actix-web/Actix-web.md) (Rust)
3. [Rocket](./Rocket/Rocket.md) (Rust, type-safe)

#### **Learning Backend Development**
1. Foundation: [Node.js](./Node.js/Node.js.md)

## 🔧 Installation Summary

### Quick Start Commands

**Express**
```bash
npm init -y && npm install express
npx express-generator my-app
```

**NestJS**
```bash
npm install -g @nestjs/cli
nest new my-app
```

**Fastify**
```bash
npm install fastify
npm install -D nodemon
```

**Adonis**
```bash
npm install -g @adonisjs/cli
adonis new my-app
```

**Sails**
```bash
npm install -g sails
sails new my-app
```

**Actix-web (Rust)**
```bash
cargo new my-app
cargo add actix-web
```

**Rocket (Rust)**
```bash
cargo new my-app
cargo add rocket --features json
```

## 📋 Choosing Your Framework

### Decision Tree

```
START
  ├─ Use JavaScript/Node.js?
  │   ├─ Yes, want speed?
  │   │   ├─ Yes → Use Fastify
  │   │   └─ No → Use Express or Koa
  │   ├─ Yes, want Rails-like?
  │   │   ├─ Yes → Use Adonis or Sails
  │   │   └─ No → Use NestJS
  │   └─ Yes, need realtime?
  │       ├─ Yes → Use Sails or Express+Socket.io
  │       └─ No → Choose above
  └─ Use Rust?
      ├─ Speed critical? → Use Actix-web
      ├─ Modern patterns? → Use Axum
      ├─ Type-safe + DX? → Use Rocket
      └─ Something else → Check other sections
```

## 🎯 Popular Use Cases

### SaaS Application
- **Framework**: NestJS + React/Vue
- **Reasoning**: Type safety, scalability, full-stack
- **Guide**: [NestJS](./NestJS/NestJS.md)

### REST API for Mobile
- **Framework**: Fastify or Express
- **Reasoning**: Performance, simplicity, ecosystem
- **Guide**: [Fastify](./Fastify/Fastify.md) or [Express](./Express/Express.md)

### Real-time Chat Application
- **Framework**: Sails.js + Socket.io
- **Reasoning**: Built-in WebSocket, MVC structure
- **Guide**: [Sails.js](./Sails.js/Sails.js.md)

### Microservices Architecture
- **Framework**: NestJS + Fastify
- **Reasoning**: Modularity, performance, features
- **Guide**: [NestJS](./NestJS/NestJS.md)

### High-Traffic API
- **Framework**: Actix-web (Rust)
- **Reasoning**: Maximum performance, type safety
- **Guide**: [Actix-web](./Actix-web/Actix-web.md)

- **Framework**: Adonis.js
- **Reasoning**: Built-in ORM, validation, migrations
