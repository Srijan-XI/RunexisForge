# Remix

## Introduction

## Overview

Remix is a full-stack React framework focused on web standards, leveraging server rendering, nested routes, and progressive enhancement.

## Key Features

- Nested routing with loaders and actions for data
- Built-in forms with progressive enhancement
- Server-first by default; adapts to edge runtimes
- TypeScript support and file-based routing
- Works with various deployments (Node, Vercel, Cloudflare, Fly.io)

## Common Use Cases

- Data-driven apps with strong form handling
- SEO-friendly sites with fast streaming responses
- Edge-rendered apps for low latency

## Resources

- Docs: <https://remix.run/docs>
- Stacks: <https://remix.run/stacks>

# Remix Usage Guide

## Create a Project

```bash
npx create-remix@latest
# choose TypeScript and a deploy target (Node, Vercel, Cloudflare, etc.)
cd <app>
npm install
```bash

## Run

```bash
npm run dev
```bash

## Routing

- File-based under `app/routes/`
- Nested routes: `app/routes/dashboard.tsx` and `app/routes/dashboard.settings.tsx`
- Dynamic params: `app/routes/blog.$slug.tsx`

## Loaders and Actions

```tsx
export async function loader() {
  return json({ message: 'Hello' });
}

export async function action({ request }) {
  const data = await request.formData();
  return redirect('/thanks');
}
```bash

Use `useLoaderData` and `useActionData` in components.

## Styling

- CSS files imported per route: `import styles from './route.css';`
- Tailwind: `npx tailwindcss init -p` and add to `app/root.tsx`

## Deployment

- Node adapter: `npm run build && npm run start`
- Vercel/Cloudflare use appropriate adapters generated by create-remix

## Testing

- Unit: Vitest/Jest
- E2E: Playwright or Cypress
