# Network Tools

A comprehensive collection of networking tools organized by functionality.

## 📂 Categories

### 01-Message-Brokers
Message queue systems, messaging protocols, and real-time communication frameworks.

- **ActiveMQ** - Apache's open-source message broker
- **AMQP** - Advanced Message Queuing Protocol
- **MQTT** - Lightweight messaging protocol for IoT
- **NATS** - High-performance cloud-native messaging system
- **RabbitMQ** - Feature-rich message broker
- **Redis-Streams** - Redis-based streaming platform
- **Socket.io** - Real-time bidirectional event-based communication
- **WebSocket** - Full-duplex communication protocol

### 02-Network-Scanning
Tools for network discovery, port scanning, and host enumeration.

- **Angry IP Scanner** - Fast network scanner
- **ARP-scan** - ARP-based network scanner
- **Nmap** - Network exploration and security auditing
- **ZMap** - Fast internet-wide network scanner

### 03-Wireless-Security
Wireless network security testing and analysis tools.

- **Aircrack-ng suite** - Complete suite of wireless security tools
- **Airmon-ng** - Wireless monitoring mode enabler
- **BlueMaho** - Bluetooth security testing toolkit
- **Kismet** - Wireless network detector and IDS
- **Wifite** - Automated wireless attack tool

### 04-Packet-Analysis
Network traffic capture, analysis, and manipulation tools.

- **Bettercap** - Network attack and monitoring framework
- **Ettercap** - Network interceptor and sniffer
- **tcpdump** - Command-line packet analyzer
- **Wireshark** - Network protocol analyzer

### 05-Network-Utilities
General-purpose networking tools and utilities.

- **Hping** - TCP/IP packet assembler/analyzer
- **iftop** - Real-time network bandwidth monitoring
- **iperf** - Network performance measurement tool
- **Netcat** - Networking utility for reading/writing network connections

### 06-Network-Simulation
Network simulation and training environments.

- **Packet-Tracer** - Cisco network simulation tool

## 📖 Usage Guidelines

Each tool has its own dedicated folder containing documentation and resources. Navigate to the specific category and tool folder for detailed information.

## ⚠️ Security Notice

Many tools in this collection are designed for security testing and network analysis. Always:
- Use tools only on networks you own or have explicit permission to test
- Follow responsible disclosure practices
- Comply with local laws and regulations
- Understand the tool before using it
